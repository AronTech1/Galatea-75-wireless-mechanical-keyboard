Galatea is a 75% wireless mechanical keyboard built around an ESP32-P4 (400 MHz RISC-V, native MIPI-DSI) paired with an ESP32-C6 companion module that provides Wi-Fi 6 and Bluetooth LE through Espressif’s ESP-Hosted. A 5" 720×1280 IPS display, driven over a two-lane MIPI-DSI link with a boost-powered backlight, sits beside the 83-key matrix. The matrix is scanned by two I²C TCA8418 key-scanner chips, and IS31FL3733 matrix drivers control per-key white LEDs and the lit action and voice buttons. The board also has a rotary encoder, three programmable action buttons, a dedicated voice button with an I²S microphone, and a 5000 mAh Li-Po battery. Power comes from a USB-C input through an MP2617 NVDC charger with power-path management, feeding a buck-boost 3.3 V rail, a 1.8 V LDO, a dedicated 1.2 V core supply and a MAX17048 fuel gauge.
